# Movie 2 ASCII

カメラから取得したフレームをリアルタイムでASCIIアートに変換します。ターミナル上でカラー表示にも対応。

## 必要なライブラリ

```bash
pip install opencv-python
```

## 実行方法

```bash
python main.py
```

## 操作方法

| キー | 内容 |
|------|------|
| `c` | カラー / モノクロ 切替 |
| `r` | ASCIIの明暗を反転 |
| `q` | 終了 |

## 仕組み

OpenCVでカメラフレームを取得し、グレースケール化した後に輝度をASCII文字にマッピング。カラーモードではANSI 24bitエスケープシーケンスで出力しています。

## 注意点

- Windows 専用（`msvcrt` でキー入力取得）
- ターミナルが ANSI エスケープ対応している必要がある
